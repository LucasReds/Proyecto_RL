# Transfer Learning con PPO en Entornos de Navegación

Este repositorio contiene los experimentos, código y análisis del proyecto **Transfer Learning para Aprendizaje Reforzado** usando **Proximal Policy Optimization (PPO)** como algoritmo base.  
El objetivo es evaluar si transferir los pesos desde un entorno simple permite acelerar la convergencia en entornos más complejos (grillas más grandes, paredes aleatorias, recompensas escasas).

Se necesita tener instalado la libreria de StableBaslines3, matplotlib, numpy, y pandas.
